# dev-scripts

Разовые скрипты, которыми что-то проверяли во время разработки: клики по окну,
поиск рабочего стола, перекодировка файлов, проверка уровня целостности,
перемещение курсора и прочее. К сборке и работе приложения отношения не имеют —
сюда же ушли старые тестовые проекты (`parent-test`).

Держим отдельно от `tools/`, потому что в `tools/` только то, что реально
пригодится снова: скриншоты, обрезка, иконка, замер полосы, инфо об окне,
дамп значков трея, UIA-зонд.

Удалять не обязательно: места много, истории не мешают.
