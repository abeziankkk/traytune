# История изменений

Формат — по мотивам [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/):
разделы «Добавлено», «Изменено», «Исправлено», «Удалено». Версии — по
[семантическому версионированию](https://semver.org/lang/ru/).

Что было до первого публичного релиза — только во внутренних заметках
разработки, они не публикуются.

## Не выпущено

### Добавлено

- **Бегущая строка для длинных названий.** Если название не помещается в виджет,
  оно едет влево с паузой на старте; включается и выключается в настройках.
- **Цвет акцента из обложки.** Новый режим «Из обложки»: берётся доминирующий
  цвет обложки, с поправкой на читаемость на тёмной панели задач.

### Исправлено

- **Полоса воспроизведения больше не прыгает назад.** Причины было две:
  в состояние записывалась «сырая» позиция из SMTC (окно успевало нарисовать
  её на один кадр), а метка времени ставилась «сейчас», хотя SMTC отдаёт
  позицию на момент `LastUpdatedTime` — из-за этого цель каждую секунду
  откатывалась назад. Теперь позицию считает только `Tick()`, метка берётся
  из SMTC (с защитой от мусорных значений), отложенный скачок применяется до
  отрисовки, а на паузе перемотка отображается сразу.

### Изменено

- Перезапуск после релиза больше не требует ручной чистки: программа сама
  возвращает папке `%TEMP%\.net` обычные права, если её создал повышенный процесс.
- В `Troubleshooting.txt` добавлен раздел 8 — что делать, если приложение
  запускается само.
- Разовые отладочные скрипты вынесены из `tools/` в `dev-scripts/`; в `tools/`
  осталось только то, что пригодится снова.

## 0.2.0 — 2026-11-06

### Добавлено

- Настоящее встраивание виджета в панель задач (`SetParent` + `WS_CHILD`)
  и режим совместимости поверх панели, если Windows встраивание не разрешает.
- Окно настроек: положение (слева/центр/справа), ширина (280/340/400), фон
  (прозрачный под TranslucentTB, полупрозрачный, тёмный), цвет акцента по
  источнику (Spotify, Яндекс, градиент «волна», вручную), показ полосы,
  автозапуск.
- Значок в трее с устойчивым AppUserModelID и попыткой включить «показывать
  всегда» на Windows 11.
- Ключи запуска `--show`, `--dock`, `--undock`, `--settings`.
- Переменные окружения `TRAYTUNE_DATA` и `TRAYTUNE_INSTANCE` — для тестов.
- `Troubleshooting.txt` — памятка рядом с exe.
- `DEVELOPMENT.md` — сборка, структура, грабли, отладка.

### Изменено

- Запуск без запроса UAC: манифест `asInvoker`, никаких задач планировщика.
- Позиция считается по монотонным часам, отставание SMTC догоняется скоростью,
  мелкое дрожание длительности игнорируется.
- Защита от второго экземпляра: повторный запуск открывает настройки уже
  работающей копии.

### Исправлено

- Клики по виджету больше не проваливаются в панель задач.
- Контекстное меню не уезжает за нижний край экрана.
- Кэш обложки обновляется только по успешным ответам.

## 0.1.0 — 2026-10-29

Первый публичный релиз: виджет с обложкой, названием и артистом, управление
play/pause, следующий/предыдущий трек, перемотка по клику, две сборки
(portable и для .NET 10).
